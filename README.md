# Personal Portfolio Website

## 📌 About the Project

This is my personal portfolio website created to showcase my skills, projects, certifications, achievements, and contact information.

The website provides a simple and professional way for recruiters and visitors to learn more about me and my work.

## ✨ Features

- Professional homepage
- About Me section
- Skills section
- Projects section
- Certifications and Achievements section
- Contact section
- GitHub and LinkedIn links
- Responsive design for desktop and mobile devices
- Smooth scrolling navigation
- Contact form

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Formspree
